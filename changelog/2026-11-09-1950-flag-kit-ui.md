### 2026.11.09.1950

> A SwiftUI app reads each flag with `@FlagState`, and a debug screen lists every flag with where its value came from.

- Feat: the `FeatureFlagKitUI` product, on the core and SwiftUI only, with the environment's `flagStore` set to the live store by default.
- Feat: `@FlagState(key)` reads a flag in a view, redraws on its change, and binds the user's own toggle through `$binding`.
- Feat: `FlagDebugView(catalog:)` shows every flag's value, layer and expiry day, with an override-aware toggle and "Reset all".
- Docs: requirements 0004 and 0005, the default live store's redraw included, the architecture views, and the README.
