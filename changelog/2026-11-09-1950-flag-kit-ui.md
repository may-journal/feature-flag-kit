### 2026.11.09.1950

> A SwiftUI app reads each flag with `@FlagState`, and a debug screen lists every flag with where its value came from.

- Feat: the `FeatureFlagKitUI` product, on the core and SwiftUI only, with the environment's `flagStore` set to one shared live store.
- Feat: `@FlagState(key)` reads a flag in a view, redraws on its change through one listener, and binds the user's toggle via `$binding`.
- Feat: `FlagDebugView(catalog:)` shows each flag's value, layer and expiry day, with a toggle or number field and a confirmed "Reset all".
- Docs: requirements 0004 to 0006, Debug-only previews of the debug screen, the architecture views, and the README.
- Chore: the FlagDebugDemo app shows those previews with StorybookKit.
